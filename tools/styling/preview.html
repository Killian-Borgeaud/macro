Callouts

Two callout styles are used throughout: the key concept box highlights a definition or result the reader must internalize, and the example box gives a concrete illustration or worked numeric case.

Key concept. The steady state $k^*$ is the level of capital per worker at which gross investment $s f(k)$ exactly offsets effective depreciation $(n + \delta) k$. Algebraically, $k^*$ solves $s f(k^*) = (n + \delta) k^*$.

A short paragraph between callouts. The vertical rhythm should keep callouts visually grouped with the prose that introduces them, not floating.

Example. With $f(k) = k^{0.3}$, $s = 0.2$, $n = 0.01$, $\delta = 0.04$, the steady state is $k^* = (s/(n+\delta))^{1/(1-\alpha)} = (0.2/0.05)^{1/0.7} \approx 6.96$. Steady-state output per worker is $y^* = (k^*)^{0.3} \approx 1.74$.

Derivation with Display Math

We derive the steady-state capital per worker step by step. Start from the law of motion:

$$\Delta k_t = s f(k_t) - (n + \delta) k_t.$$

At a steady state $k^*$, the change is zero by definition:

$$0 = s f(k^*) - (n + \delta) k^*.$$

Rearranging,

$$\frac{f(k^*)}{k^*} = \frac{n + \delta}{s}.$$

With Cobb-Douglas $f(k) = k^{\alpha}$, this becomes

$$(k^*)^{\alpha - 1} = \frac{n + \delta}{s} \quad\Longrightarrow\quad k^* = \left(\frac{s}{n + \delta}\right)^{\frac{1}{1 - \alpha}}.$$

And a code block:

def steady_state(s, n, delta, alpha):
    return (s / (n + delta)) ** (1 / (1 - alpha))

k_star = steady_state(s=0.2, n=0.01, delta=0.04, alpha=0.3)
print(f"k* = {k_star:.4f}")  # k* = 6.9588
