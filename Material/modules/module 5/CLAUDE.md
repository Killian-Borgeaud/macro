# Module 5 — Endogenous Growth without Scale Effects

Maps to **Lecture 5** in the course plan. **No textbook chapter** — this module is taught from Prof. Cozzi's own lecture notes only.

## Files in this module

- `Lecture 5a.md` — From "endogenous" to "truly endogenous" growth: distinguishes semi-endogenous (Jones 1995, Kortum 1997, Segerstrom 1998 — policy cannot affect long-run growth) from truly-endogenous-with-scale-effect (Romer 1995, Aghion-Howitt 1992). Builds the truly-endogenous R&D-driven model without scale effect.
- `Lecture 5b.md` — Both "semi-endogenous" and "truly endogenous" growth? The hybrid model (Smulders-Van de Klundert 1995, Dinopoulos-Thompson 1998, Peretto 1998, Young 1998, Howitt 1999). What if both theories are right?
- `Slides_Session5.md` — Exercise session by Maria Bolboaca: R&D model (Exercise 5.1a-f), truly endogenous without scale effects (5.1g), and the hybrid model (5.2). Lists 8 parameters (α, s, s_R, n, ϕ, ρ, λ, δ) and 8 endogenous variables for the R&D model.

For visually-heavy pages (model diagrams, simulation plots), use the corresponding `.pages/p{NNN}.png` files.
